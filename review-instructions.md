# Инструкция для AI-помощника

## Цель

Проверить код проекта clean-code-todo на проблемы из модуля Clean Code: мёртвый код, дублирование обработчиков и логики, нечитабельные имена переменных и функций, комментарии, пересказывающие код, функции, которые сложно прочитать целиком. Не изменять файлы, только анализировать и объяснять.

## Границы

- Проверять только файлы приложения: app.js, index.html, style.css, README.md.
- Не трогать .github/workflows/check.yml, .husky/pre-commit, конфиги инструментов.
- Не редактировать файлы, не создавать новые версии кода.
- Не предлагать переписывание на фреймворк или добавление сборщиков.

## Критерий готовности

Ревью завершено, когда в файле review-report.md на русском языке собран отчёт с замечаниями, сгруппированными по категориям из задания. Каждое замечание содержит:

- место в коде (файл, строка);
- проблема;
- условие, при котором она проявляется;
- способ проверить исправление.

## Формат вывода

Отчёт сохраняется в review-report.md в корне проекта. Замечания сгруппированы по категориям из задания. Помощник не вносит правки в код, только объясняет. Окончательные решения принимает автор.
